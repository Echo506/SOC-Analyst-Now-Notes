# Preparación para entrevista de SOC Analyst

## Preguntas técnicas para practicar
- ¿Qué es una dirección RFC1918?
- ¿Cuál es la diferencia entre TCP y UDP?
- ¿Qué servicios suelen usar los puertos 80, 443, 22, 23, 25 y 53?
- ¿Qué es una DMZ y por qué puede ser objetivo de ataques?
- ¿Qué es la exfiltración de datos?
- ¿Cuáles son las fases de Cyber Kill Chain?
- ¿Cuál es el propósito de MITRE ATT&CK?
- ¿Qué es un SIEM?
- ¿Cómo investigarías una alerta de inicio de sesión sospechoso?
- ¿Qué evidencias recolectarías ante un posible phishing?

## Estrategia de respuesta
1. Explicar el concepto de forma clara y breve.
2. Relacionarlo con un caso práctico.
3. Indicar cómo validarías la información usando logs, herramientas o procedimientos.
4. Mencionar cuándo escalarías el evento.

## Ejemplo: alerta de inicio de sesión sospechoso
Verificaría el usuario afectado, dirección IP de origen, geolocalización, hora del evento, método de autenticación, dispositivos conocidos y actividad posterior al inicio de sesión. Si identifico indicios de compromiso, documentaría las evidencias y escalaría según el procedimiento de respuesta a incidentes.
